# Lyra – demo

**Lyra** (čita se „Lira“, po zviježđu Lire) je obiteljska aplikacija u kojoj djeca za trud skupljaju zvjezdice – velike i male – uz pravu magnetnu ploču na zidu.

Ovo je **demo s izmišljenom obitelji** (Ema, Toni i Mališa). Svi podaci su izmišljeni.

- Otvori: https://vxgdrive-hue.github.io/lyra-demo/
- Na mobitelu: izbornik preglednika → „Instaliraj aplikaciju“ / „Dodaj na početni zaslon“
- Promjene ostaju samo u tvom pregledniku; tipka **↺ Na početak** vraća demo na početno stanje
- Demo PIN: 1234
